Tell a Whole Story in 32 Characters — one Wi-Fi network name, one whole story.

## The entry

```
SheTookTheDogAndTheRouter
```

25 characters. She left, took the dog, and took the router too: a breakup
told in a single network name. The router is the punchline — listed next to
the dog as if it were the other thing worth fighting over.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

Writes the single line to `/output/entry.txt` (mode 644). Deterministic:
every run produces the same bytes.
